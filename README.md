# Кейс-задача № 3 — Учет кадров Университета «Синергия»

Консольная программа на C# для отдела кадров АНО ВО «Московский университет «Синергия».

## Что делает программа
- Ввод данных сотрудников с клавиатуры (ФИО, должность, зарплата, год поступления на работу);
- Расчет стажа работы каждого сотрудника;
- Поиск и вывод сотрудников, чей стаж превышает значение, введенное с клавиатуры;
- Вывод сообщения, если таких сотрудников нет.

## Структура проекта
| Файл | Назначение |
|---|---|
| `Worker.cs` | Отдельный модуль с классом `Worker` (поля, конструкторы, деструктор, методы) |
| `Program.cs` | Основная программа: ввод данных, список `List<Worker>`, поиск по стажу |
| `SynergyWorkerCase.csproj` | Файл проекта (.NET 8.0) |

## Класс Worker
- **Поля:** фамилия и инициалы, должность, зарплата, год поступления на работу.
- **Конструкторы:** по умолчанию, с параметрами, копирования. **Деструктор:** `~Worker()`.
- **Методы:** сеттеры/геттеры полей, `GetExperienceYears()`, `HasExperienceMoreThan()`, `Display()`.
